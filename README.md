🚀 Getting Started
Clone this repository:

bash
git clone https://github.com/yourusername/portfolio-site.git
cd portfolio-site
Open index.html in your web browser to preview.

Deploy using GitHub Pages:

Push your code to your GitHub repository

Go to repository Settings > Pages

Set branch as main and folder as /root

Your site will be published on https://yourusername.github.io/portfolio-site/

Customize Content:

Replace personal info, projects, and social links in index.html

Update images & icons (/assets/ folder)

Add your own branding!
