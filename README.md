## Getting Started

Clone this repository:

```bash
git clone https://github.com/rickCensor/rickCensor.github.io.git
cd rickCensor.github.io
```

Open `index.html` in your web browser to preview the site locally.

Deploy using GitHub Pages

- If this repository is named `rickCensor.github.io` (a user site), GitHub Pages will publish the site from the repository's default branch at:
  https://rickcensor.github.io/

- If you're using a different repository name (project site), follow these steps:
  1. Push your code to a GitHub repository.
  2. Go to the repository Settings → Pages.
  3. Under "Build and deployment", select the branch you want to publish from (usually `main`) and the folder (`/ (root)`).
  4. Save — GitHub will show the published URL.
